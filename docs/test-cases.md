# 테스트 케이스

- **프로젝트명**: 그린이슈(Green Issue)
- **작성일**: 2026-11-17
- **배포 주소**: https://dotdot1102.github.io/my-shop/
- **기준 문서**: docs/prd.md (요구사항 정의서, R-01 ~ R-20)

> **처음 보는 분을 위한 안내**
>
> - **환경 표기**: '데스크톱'은 컴퓨터 브라우저에서 마우스로, '모바일 390px'은 화면 폭 390px에서 탭으로 확인한다는 뜻이에요.
> - **화면 폭 390px 만들기 (크롬)**: F12로 개발자 도구를 열고 Ctrl+Shift+M(맥은 Cmd+Shift+M)을 누른 뒤, 위쪽 너비 칸에 390을 입력해요. 이 상태에서는 마우스 클릭이 손가락 탭처럼 동작해요.
> - **처음 상태로 되돌리기**: 이 사이트는 회원·장바구니·주문을 브라우저에만 저장해요. 장바구니를 비우거나 로그아웃된 처음 상태가 필요하면 F12 → Application 탭 → Storage → 'Clear site data'를 누르고 새로고침해요.
> - **로그아웃**: 오른쪽 위 '마이페이지' 버튼 → '회원 정보' 아래 '로그아웃' 버튼을 눌러요.
> - **무료권이 남은 회원**: 새 이메일로 막 가입한 회원이에요. 무료권을 한 번 쓰면 다시 생기지 않으니, 필요할 때마다 새 이메일로 가입해요.
> - **예시 입력값**: 이메일은 test1@example.com처럼 매번 다른 값, 비밀번호는 8자 이상(예: testpass88), 전화번호는 01012345678, 주문 비밀번호는 1234를 쓰면 돼요.
> - **괄호 안 ID**: (M-03), (P-04) 같은 표기는 요구사항 정의서와 맞춰 보기 위한 화면·버튼 ID예요. 따라 할 때는 앞의 화면 이름과 버튼 글자를 보면 돼요.
> - **결과 칸**: 확인한 뒤 '통과' 또는 '실패'를 적어요.
