# 그린이슈(Green Issue) 사이트 페이지 구성

- 기준 문서: docs/01-site-purpose.md
- 주요 기기: 데스크톱 기준
- 문서 상태: 페이지 구성 확정본 (화면·코드 작업 전)
- 표기: **확정** = 결정한 내용 / **추후 결정** = 아직 정하지 않은 내용
- 변경 기록: 2026-11-12 회원가입·로그인을 가벼운 페이지 하나로 합침, 혜택 안내는 홈에 한 줄, 루틴 만들기는 가입·로그인 후 이용 / 루틴 완성 혜택을 정기배송 첫 회 무료로 변경 / 배송비 기준 결정 — 5만 원 이상 무료배송, 무료권을 쓴 주문은 함께 담은 상품까지 배송비 무료 / 루틴 혜택 확대 — 루틴 구성 정기배송은 첫 회 무료 + 배송비 매회 무료 + 가입 무료 단품을 첫 상자에 동봉

## 1. 방문자 흐름

| # | 방문자 행동 | 필요한 정보·기능 | 배치할 페이지·섹션 | 다음 행동 | 상태 |
|---|---|---|---|---|---|
| 1 | 사이트에 처음 들어옴 | 어떤 브랜드인지 한눈에 파악 (브랜드 문장) | [홈] 첫 화면 | 루틴 만들기 또는 상품 둘러보기 | 확정 |
| 2 | 무엇을 파는지 확인 | 당근주스·케일주스·사과칩 소개, 언제·어떻게 먹으면 좋은지 | [홈] 상품 섹션 | 루틴 만들기 | 확정 |
| 3 | 가입 혜택 확인 | 가입하면 단품 1회 무료권 + 무료권 주문 무료배송. 배너·팝업 없이 문장 한 줄 | [홈] 상품 섹션 아래 한 줄 | 회원가입 또는 루틴 만들기 | 확정 |
| 4 | 믿어도 되는지 확인 | 재료와 만드는 방식 | [홈] 브랜드 섹션 | 루틴 만들기 | 확정 (섹션에 넣을 내용은 추후 결정) |
| 5 | 회원가입 또는 로그인 | 상단 메뉴 가입 버튼이나 루틴 만들기 진입 시 열림. 가입 양식 + 혜택 한 줄 + "이미 회원이신가요? 로그인" | [회원가입·로그인] | 루틴 만들기로 돌아옴 또는 정기배송 신청 | 확정 (로그인 방식은 추후 결정) |
| 6 | 섭취 루틴 만들기 | 가입·로그인한 방문자만 이용. 비회원은 [회원가입·로그인]을 거친 뒤 돌아옴. 출근 시간·생활 패턴 선택 | [루틴 만들기] 선택 영역 | 바로 아래에서 결과 확인 | 확정 (질문 항목은 추후 결정) |
| 7 | 내 루틴 결과 확인 | 언제 무엇을 먹을지, 정기배송 구성 제안. 선택 바로 아래에 표시하고 선택을 바꾸면 결과도 바뀜. 결과는 계정에 저장 | [루틴 만들기] 결과 영역 (같은 페이지) | 정기배송 신청 | 확정 |
| 8 | 루틴 혜택 확인 (루틴 완성자) | 이 구성으로 정기배송을 신청하면 첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉. 팝업 없이 결과 영역 안에서 차분한 문장으로 안내 | [루틴 만들기] 결과 영역 안 | 정기배송 신청 | 확정 |
| 9 | 정기배송 조건 확인 | 주 1회 배송, 해지·변경은 언제든 간단하게 | [정기배송 신청] 조건 안내 | 신청 진행 | 확정 |
| 10 | 정기배송 신청 | 루틴을 만든 방문자는 저장된 루틴 구성대로(루틴 혜택 자동 적용: 첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉), 루틴이 없는 방문자는 상품을 직접 골라 신청 | [정기배송 신청] 구성 선택 + 신청 양식 | 신청 완료 확인 | 확정 (입력 항목·가격·결제 방식은 추후 결정) |

## 2. 페이지 구성 (확정)

| 페이지 | 묶은 기능 |
|---|---|
| 홈 | 첫 화면, 상품 섹션, 가입 혜택 안내 한 줄(상품 섹션 아래), 브랜드 섹션 |
| 루틴 만들기 | 가입·로그인 확인, 선택 영역, 결과 영역(같은 페이지), 루틴 혜택 안내 |
| 정기배송 신청 | 조건 안내, 구성 선택(루틴 구성 + 루틴 혜택 또는 상품 직접 선택), 신청 양식, 완료 확인 |
| 회원가입·로그인 | 가입 양식, 혜택 한 줄, 로그인 링크 (가벼운 페이지 하나) |

## 3. 고른 대안과 이유

| 선택 항목 | 고른 대안 | 이유 |
|---|---|---|
| 상품 소개 위치 | 홈 안의 섹션 | 상품이 3개뿐이라 한 페이지로 충분하고, 이동 없이 바로 루틴 만들기로 넘어갈 수 있음 |
| 브랜드 이야기 위치 | 홈 안의 섹션 | '정직하고 믿을 수 있음'을 첫 방문에서 바로 느끼게 할 수 있음 |
| 루틴 결과 표시 방식 | 같은 페이지에서 선택 바로 아래에 표시 | 흐름이 끊기지 않고, 선택을 바꾸면서 결과를 다시 볼 수 있음 |
| 루틴 없는 방문자 혜택 | 회원가입자에게 단품 1회 무료권 증정 | 루틴을 만들지 않은 방문자에게도 첫 경험의 문턱을 낮춤 |
| 회원가입자 무료배송 범위 | 무료권을 쓴 주문 전체 (함께 담은 다른 상품 포함) | 한 상자로 가므로 배송비 원가가 거의 같고, 더 담았다고 배송비가 생기는 어색함을 없앰. 첫 경험의 문턱을 낮추는 의도와 맞음 |
| 일반 무료배송 기준 | 5만 원 이상 구매 시 무료배송 | 사용자 결정 (2026-11-12) |
| 루틴 없이 정기배송 신청 | 가능, 상품을 직접 골라 신청 | 루틴을 만들지 않은 방문자도 핵심 행동인 정기배송 신청까지 갈 수 있음 |
| 회원가입 페이지 규모 | 가입 양식만 있는 가벼운 페이지, 가입 버튼에서 열림 | 핵심 행동은 정기배송 신청이고, 가입은 그 길목이면 충분함. 팝업이 아닌 페이지라 '팝업 없이' 원칙과 맞음 |
| 로그인 위치 | 회원가입 페이지에 함께 둠 | 페이지를 하나 줄여 구조를 단순하게 유지 |
| 가입 혜택 안내 위치 | 홈 상품 섹션 아래 문장 한 줄 | 상품 소개 흐름 안에서 자연스럽게 알림. 할인 배너·구매 재촉 연출을 피함 |
| 루틴 만들기 이용 조건 | 가입·로그인 후 이용 | 무료권을 받는 길이 가입 하나로 모이고, 루틴 결과를 계정에 저장해 정기배송 신청으로 그대로 넘길 수 있음 |
| 루틴 완성 혜택 | 루틴을 만든 가입자가 루틴 구성으로 정기배송을 신청하면 첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉 (자동 적용, 무료 단품은 무료권을 아직 쓰지 않은 경우) | 혜택을 핵심 행동인 정기배송 신청과 연결. 매주 받는 고객이 5만 원 기준 때문에 배송비를 내지 않도록 하고, 무료 단품은 첫 상자에 넣어 따로 주문할 필요를 없앰 |

## 4. 추후 결정

- [ ] 5만 원 미만 주문의 배송비 금액
- [ ] 루틴 없이 상품을 직접 골라 정기배송을 신청한 경우 회차별 배송비(5만 원 기준) 적용 여부
- [ ] 가입 무료권 대상 상품
- [ ] 루틴을 만든 가입자가 루틴 구성 대신 상품을 직접 골라 신청해도 루틴 혜택(첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉)을 주는지
- [ ] 로그인 방식 (이메일, 소셜 로그인 등)
- [ ] 홈 브랜드 섹션에 넣을 재료·만드는 방식 내용
- [ ] 루틴 만들기 질문 항목
- [ ] 정기배송 신청 양식의 입력 항목, 가격, 결제 방식
