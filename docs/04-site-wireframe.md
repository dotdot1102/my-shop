### 배치

- **위쪽 행:** 주요 동선 페이지를 순서대로 놓았습니다. ① P-01 홈 → ② P-02 회원가입·로그인 → ③ P-03 루틴 만들기 → ④ P-04 정기배송 신청
  - ① → ② 화살표: 루틴 만들기 (비회원)
  - ② → ③ 화살표: 가입·로그인 후 돌아옴
  - ③ → ④ 화살표: P03-B01
- **아래쪽 행:** 주요 동선 밖의 추후 결정 페이지(P-05, P-06)와 버튼·목적지 연결 표를 놓았습니다.
- 각 프레임 안에서는 페이지 ID 줄, 공통 메뉴, 섹션 순서로 위에서 아래로 쌓았습니다.

### 표기 규칙 (Figma 범례와 같음)

| 요소 | 표현 |
|---|---|
| 텍스트 | 회색 선. 굵은 선은 제목, 가는 선은 본문 |
| 이미지 | X 상자 |
| 입력 | 흰 칸 + 회색 테두리 (높이 48) |
| 선택 | 칩, 탭, 체크박스. 선택된 것은 연회색 채움 + 진한 테두리 |
| 조절 | 슬라이더(출근 시간), 수량 조절 − / + |
| 버튼 | 진회색 채움(주요), 흰 칸 + 회색 테두리(보조), 밑줄 텍스트(텍스트 링크). 버튼 이름은 실제 글자로 표기 |
| 핵심 행동 | 버튼에 3px 검정 테두리 + '핵심 행동' 라벨 |
| ID | 검정 라벨 (메뉴 M-, 페이지 P-, 섹션 Pxx-Sxx, 버튼 Pxx-Bxx) |
| 추후 결정 | 회색 점선 라벨 '추후 결정 · 항목' / 페이지는 점선 프레임 |
| 메모 | 회색 작은 글씨 '메모: …' (화면 문구가 아닌 설명) |
| 색 | 검정·흰색·회색만 사용 |
