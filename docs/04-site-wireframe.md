### 배치

- **1행:** 주요 동선 페이지를 순서대로 놓았습니다. ① P-01 홈 → ② P-02 회원가입·로그인 → ③ P-03 루틴 만들기 → ④ P-04 정기배송 신청
  - ① → ② 화살표: 루틴 만들기 (비회원)
  - ② → ③ 화살표: 가입·로그인 후 돌아옴
  - ③ → ④ 화살표: P03-B01
- **2행:** 주요 동선 밖에서 구현한 페이지 — P-05 주문하기, P-06 마이페이지, P-07 상품 더보기, P-08 상품 상세
- **3행:** P-09 장바구니, P-10 비회원 주문 조회, 첫 화면(인트로), 버튼·목적지 연결 표
- 각 프레임 안에서는 페이지 ID 줄, 공통 메뉴, 섹션 순서로 위에서 아래로 쌓았습니다. (첫 화면은 공통 메뉴 없음)
- 처음 초안의 '추후 결정' P-05(단품 주문·무료권 사용) · P-06(내 정기배송) 점선 프레임은 지금의 P-05 주문하기 · P-06 마이페이지로 대체했습니다.

### 표기 규칙 (Figma 범례와 같음)

| 요소 | 표현 |
|---|---|
| 텍스트 | 실제 화면 문구로 표기. 굵은 글씨는 제목 |
| 이미지 | X 상자 |
| 입력 | 흰 칸 + 회색 테두리 (높이 48). 필수 칸은 이름 뒤 '*' |
| 선택 | 칩, 탭, 체크박스. 선택된 것은 연회색 채움 + 진한 테두리 |
| 조절 | 슬라이더(출근 시간), 수량 조절 − / + |
| 버튼 | 진회색 채움(주요), 흰 칸 + 회색 테두리(보조), 밑줄 텍스트(텍스트 링크). 버튼 이름은 실제 글자로 표기 |
| 핵심 행동 | 버튼에 3px 검정 테두리 + '핵심 행동' 라벨 |
| 상태 라벨 | 둥근 테두리 라벨 (루틴 혜택 · 남아 있어요 · 주문 접수 · 정기배송 중 등) |
| ID | 검정 라벨 (메뉴 M-, 페이지 P-, 섹션 Pxx-Sxx, 버튼 Pxx-Bxx) |
| 메모 | 회색 작은 글씨 (화면 문구가 아닌 설명) |
| 색 | 검정·흰색·회색만 사용 |
