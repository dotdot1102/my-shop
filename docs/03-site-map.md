# 그린이슈(Green Issue) 사이트맵

- 기준 문서: docs/01-site-purpose.md, docs/02-site-structure.md
- 주요 기기: 데스크톱 기준
- 문서 상태: 사이트맵 초안 (화면·코드 작업 전)
- 표기: **확정** = 기준 문서에서 결정한 내용 / **추후 결정** = 아직 정하지 않은 내용
- 변경 기록: 2026-11-12 회원가입·로그인을 가벼운 페이지 하나로 합침, 혜택 안내는 홈에 한 줄, 루틴 만들기는 가입·로그인 후 이용 / 루틴 완성 혜택을 정기배송 첫 회 무료로 변경 / 배송비 기준 결정 — 5만 원 이상 무료배송, 무료권을 쓴 주문은 함께 담은 상품까지 배송비 무료 / 루틴 혜택 확대 — 루틴 구성 정기배송은 첫 회 무료 + 배송비 매회 무료 + 가입 무료 단품을 첫 상자에 동봉

## 1. 사이트맵 (가로 계층)

```
그린이슈
├── 홈                                   [페이지 · 확정]
│   ├── 첫 화면 — 브랜드 문장             [섹션 · 확정]
│   ├── 상품 섹션 — 당근주스·케일주스·사과칩, 언제·어떻게 먹는지   [섹션 · 확정]
│   ├── 가입 혜택 안내 한 줄 — 상품 섹션 아래, 단품 1회 무료권 + 무료배송, 배너·팝업 없이   [섹션 · 확정]
│   └── 브랜드 섹션 — 재료와 만드는 방식   [섹션 · 확정 / 내용은 추후 결정]
│
├── 루틴 만들기 (가입·로그인 후 이용)      [페이지 · 확정]
│   ├── 가입·로그인 확인 — 비회원은 회원가입·로그인을 거쳐 돌아옴   [섹션 · 확정]
│   ├── 선택 영역 — 출근 시간·생활 패턴    [섹션 · 확정 / 질문 항목은 추후 결정]
│   ├── 결과 영역 — 언제 무엇을 먹을지, 정기배송 구성 제안 (선택 바로 아래, 계정에 저장)   [섹션 · 확정]
│   └── 루틴 혜택 안내 — 결과 영역 안, 팝업 없음, 이 구성으로 신청 시 첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉   [섹션 · 확정]
│
├── 정기배송 신청                         [페이지 · 확정]
│   ├── 조건 안내 — 주 1회, 해지·변경 언제든   [섹션 · 확정]
│   ├── 구성 선택 — 저장된 루틴 구성(루틴 혜택 자동 적용) 또는 상품 직접 선택   [섹션 · 확정]
│   ├── 신청 양식 — 입력 항목·가격·결제 방식   [섹션 · 확정 / 세부는 추후 결정]
│   └── 완료 확인                          [섹션 · 확정]
│
├── 회원가입 · 로그인 (가벼운 페이지 하나, 가입 버튼에서 열림)   [페이지 · 확정]
│   ├── 가입 양식                          [섹션 · 확정]
│   ├── 혜택 한 줄 — 단품 1회 무료권 + 무료권 주문 무료배송   [섹션 · 확정]
│   └── 로그인 링크 — "이미 회원이신가요? 로그인"   [섹션 · 확정 / 로그인 방식은 추후 결정]
│
├── 단품 주문 · 무료권 사용               [추후 결정 · 페이지 필요 여부]
└── 내 정기배송 (변경·해지)               [추후 결정 · 페이지 필요 여부]
```

### 주요 이동 흐름

| 출발 | 도착 | 근거 |
|---|---|---|
| 홈 | 루틴 만들기 (회원) / 회원가입·로그인 → 루틴 만들기 (비회원) | 02 방문자 흐름 5·6 |
| 상단 메뉴 가입 버튼 | 회원가입·로그인 | 02 방문자 흐름 5 |
| 루틴 만들기 결과 영역 | 정기배송 신청 (저장된 루틴 구성대로) | 02 방문자 흐름 7·10 |
| 홈 | 정기배송 신청 (상품 직접 선택) | 02 '루틴 없이 정기배송 신청' |
| 회원가입·로그인 | 루틴 만들기, 무료권 사용 또는 정기배송 신청 | 02 방문자 흐름 5 |

## 2. 하단 패널 A — 상세 페이지를 따로 분리할지

| 대상 | 결정 | 근거 |
|---|---|---|
| 상품 상세 페이지 | **분리하지 않음** (홈 상품 섹션에 포함) | 상품이 3개뿐이라 한 페이지로 충분하고, 이동 없이 바로 루틴 만들기로 넘어갈 수 있음 (02 '고른 대안') |
| 브랜드 상세 페이지 | **분리하지 않음** (홈 브랜드 섹션에 포함) | '정직하고 믿을 수 있음'을 첫 방문에서 바로 느끼게 하기 위함 (02 '고른 대안') |
| 루틴 결과 페이지 | **분리하지 않음** (루틴 만들기 같은 페이지) | 흐름이 끊기지 않고, 선택을 바꾸며 결과를 다시 볼 수 있음 (02 '고른 대안') |
| 회원가입 · 로그인 | **가벼운 페이지 하나** | 가입은 정기배송으로 가는 길목이라 가입 양식만 있으면 충분함. 로그인도 같은 페이지에 두고, 혜택 안내는 홈에 한 줄 (02 '고른 대안') |
| 단품 주문 · 무료권 사용 | **추후 결정** | 가입 후 다음 행동이 '무료권 사용'인데 이를 처리할 페이지가 페이지 구성에 없음 (02 흐름 5) |
| 내 정기배송 (변경·해지) | **추후 결정** | 01에서 '해지·변경은 조건 없이 언제든 간단하게'를 약속했으나 처리할 페이지가 페이지 구성에 없음 |

## 3. 하단 패널 B — 처리 기능 (화면이 아닌 기능)

| 기능 | 관련 페이지 | 상태 | 근거 |
|---|---|---|---|
| 로그인 · 회원 인증 | 회원가입·로그인, 루틴 만들기, 정기배송 신청 | 일부 확정 | 회원가입 페이지에 로그인을 함께 두고, 루틴 만들기는 가입·로그인 후 이용 (02 '고른 대안'). 로그인 방식(이메일·소셜)은 추후 결정 |
| 결제 | 정기배송 신청 › 신청 양식 | **추후 결정** | 가격·결제 방식이 정해지지 않음 (02 추후 결정) |
| 배송비 계산 | 정기배송 신청, 단품 주문 · 무료권 사용 | 일부 확정 | 5만 원 이상 무료배송, 무료권을 쓴 주문은 함께 담은 상품까지 배송비 무료, 루틴 구성 정기배송은 배송비 매회 무료 (02 고른 대안). 5만 원 미만 배송비 금액과 직접 선택 정기배송의 회차별 적용 여부는 추후 결정 |
| 혜택 적용 (가입 무료권 · 루틴 혜택) | 회원가입·로그인, 루틴 만들기, 정기배송 신청 | 일부 확정 | 가입 시 단품 1회 무료권 증정. 루틴을 만든 가입자가 루틴 구성으로 정기배송을 신청하면 첫 회 무료 · 배송비 매회 무료 · 가입 무료 단품 동봉 자동 적용 (01 §3). 상품 직접 선택 신청에도 루틴 혜택을 줄지는 추후 결정 |
| 가입 무료권 사용 | 단품 주문 · 무료권 사용 | **추후 결정** | 대상 상품과 사용 화면이 정해지지 않음 |
| 루틴 구성 전달 | 루틴 만들기 → 정기배송 신청 | **확정** | 루틴 만들기는 회원만 이용하므로 결과를 계정에 저장해 정기배송 신청의 구성으로 그대로 넘김 (02 흐름 7·10) |
| 정기배송 변경 · 해지 | 내 정기배송 | **추후 결정** | 01 정기배송 조건 '해지·변경은 조건 없이 언제든 간단하게' |

## 4. 추후 결정 목록

- [ ] 5만 원 미만 주문의 배송비 금액
- [ ] 루틴 없이 상품을 직접 골라 정기배송을 신청한 경우 회차별 배송비(5만 원 기준) 적용 여부
- [ ] 가입 무료권 대상 상품
- [ ] 루틴을 만든 가입자가 상품을 직접 골라 신청해도 루틴 혜택을 줄지
- [ ] 로그인 방식 (이메일, 소셜 로그인 등)
- [ ] 홈 브랜드 섹션 내용 (재료·만드는 방식)
- [ ] 루틴 만들기 질문 항목
- [ ] 정기배송 신청 양식의 입력 항목, 가격, 결제 방식
- [ ] 단품 주문 · 무료권 사용 페이지 필요 여부
- [ ] 내 정기배송 (변경·해지) 페이지 필요 여부
