# Button

행동을 부르는 버튼: 주요(primary), 보조(secondary), 핵심 행동(key action) 세 가지이며 모두 호버 시 `brand-hover` 채움에 `on-brand-hover` 글자로 바뀝니다.

- **주요** — `brand` 채움, `on-brand` 글자, 높이 56, 좌우 32, `radius-sm`, 16px Medium. 오른쪽 화살표 아이콘은 다음 단계로 넘어갈 때만.
- **보조** — 투명, 1px `ink` 테두리, `ink` 글자, 높이 52(헤더의 '가입 · 로그인'은 44, 14px).
- **핵심 행동** — P03-B01 '이 구성으로 정기배송 신청', P04-B01 '정기배송 신청하기'. 주요 버튼과 같은 모양에 너비 `form-max`(480).
- 한 화면에 주요 버튼은 하나. 페이지 이동은 `<a>`, 같은 페이지의 동작은 `<button>`.
- 색 전환 0.18초. 텍스트 링크('가입하기')는 버튼이 아니라 `brand` 밑줄 글자입니다.
