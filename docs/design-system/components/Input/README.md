# Input

라벨이 위에 붙는 한 줄 입력칸이며 가입·로그인·정기배송 신청 양식에 씁니다.

- 라벨 14px Medium, 입력칸까지 `space-2`. 높이 `input-height`(48), 좌우 `space-4`, `surface-white` 바탕, 1px `line-input` 테두리, `radius-sm`, 글자 15px.
- 포커스: `brand` 2px 외곽선(1px 띄움).
- 필드 사이 `space-6`. 가입 양식은 `form-max`(480) 한 줄, 가운데 정렬 페이지에서도 라벨은 왼쪽 정렬.
- 입력 항목 자체는 로그인 방식과 함께 아직 정하지 않았습니다.
