# ProductCard

상품 하나를 사진 → 상품명 → 재료 → 용량·가격 순서로 보여 주는 카드이며, 홈 상품 섹션에 4개가 한 줄로 놓입니다.

- 사진 4:5, `surface-photo` 바탕, 모서리 `radius-none`. 제품과 재료를 함께 찍은 밝은 사진.
- 상품명 `item-name`(17px SemiBold) · 재료 `caption`(14px, `ink-muted`) · 용량·가격 `price`(15px SemiBold) + '예시 가격' 태그(12px, `line` 테두리, `radius-xs`).
- 사진과 글 사이 `space-5`, 카드 사이 `space-8`. 테두리·그림자 없음. 호버 시 사진만 2% 확대(0.4초).
- 할인율, 배지, '인기' 같은 표시는 넣지 않습니다. 가격은 예시이므로 태그를 빼지 않습니다.
- '언제 · 어떻게 먹을지' 줄은 내용이 정해지면 `caption`으로 넣습니다(지금은 미정 표시).
