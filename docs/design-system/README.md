# Green Issue

그린이슈(Green Issue)는 잡지 편집자가 만든 자연주의 식료품 브랜드입니다. 사이트는 바쁜 30대 직장인이 간편한 섭취 방법을 확인하고 정기배송을 신청하는 곳입니다. 이 디자인 시스템은 Claude Design 캔버스 '그린이슈 메인 페이지'(P-01 홈 · P-02 회원가입·로그인 · P-03 루틴 만들기 · P-04 정기배송 신청)에 지금 적용된 값을 그대로 모은 것입니다.

> 계절이 키운 재료를 그대로 담고 꼭 필요하지 않은 것은 덜어내, 몸이 먼저 알아보는 한 잔과 한 봉지를 만듭니다.

## 원칙

- **재료가 주인공.** 화면의 색은 제품과 재료 사진에서 나옵니다. UI는 거의 흰색과 녹흑색으로만 두고, 포인트 그린(`brand`)은 행동을 부르는 곳에만 씁니다.
- **크게 외치지 않기.** 크게 키우는 글자는 페이지마다 한 곳(홈은 첫 화면 제목 `hero`)과 푸터 워드마크(`wordmark-footer`)뿐입니다. 나머지 위계는 크기보다 굵기와 색(`ink` / `ink-muted`)으로 만듭니다.
- **넓은 여백.** 섹션 사이 `space-40`(160px), 섹션 제목과 내용 사이 `space-18`(72px). 정보는 사진 아래에 작고 촘촘하게 모읍니다.
- **판촉물처럼 보이지 않기.** 할인 배너, 팝업, 배지, 구매 재촉 문구를 쓰지 않습니다. 혜택은 차분한 문장 한 줄로 안내합니다.
- **잡지를 흉내 내지 않기.** 편집자의 감각은 여백·세리프·가는 선으로만 드러내고, 제호·호수·페이지 번호 같은 잡지 장치는 쓰지 않습니다.

## 색

| 역할 | 토큰 | 쓰는 곳 |
| --- | --- | --- |
| 바탕 | `surface-page` | 기본 페이지, 헤더 |
| 흰 띠 | `surface-white` | 홈 상품·브랜드 섹션, 가입·루틴·정기배송의 본문 영역 |
| 푸터 | `surface-footer` | 공통 푸터 |
| 사진 자리 | `surface-photo` | 이미지 자리, 제품 사진 바탕 |
| 글자 | `ink` / `ink-muted` | 본문·제목 / 재료·설명·라벨 |
| 선 | `line`, `line-soft`, `line-input` | 구분선 / 흰 띠 경계 / 입력칸·칩·미정 표시 점선 |
| 포인트 | `brand` → 호버 `brand-hover` | 주요·핵심 버튼, 텍스트 링크, 선택된 칩, 메뉴 호버 밑줄, 포커스 링 |
| 딥 그린 | `brand-deep` | 푸터 워드마크만 (`surface-footer` 위 10.4:1) |

`brand`를 배경 띠, 제목, 배지에 쓰지 않습니다. 버튼 위 글자는 `on-brand`(흰색), 호버 시 `on-brand-hover`(#F6F3EC).

## 글꼴

- **Bague Scout** (`--font-display`, 파일 `fonts/BagueScout-Demo.ttf`): 푸터 워드마크 'Green Issue' 한 곳에만 씁니다. 지금 파일은 TimelessType의 데모 버전이라, 실제 사이트에 쓰기 전에 정식 라이선스를 확인해야 합니다.
- **Noto Serif KR** (`--font-serif`, Google Fonts): 히어로·페이지 제목·섹션 제목·브랜드 문장. 굵기 300–500만 씁니다.
- **Pretendard** (`--font-sans`): 메뉴, 본문, 상품 정보, 버튼, 입력. Pretendard는 Google Fonts에 없어 파일이 아직 이 시스템에 없습니다. 설치되지 않은 환경에서는 IBM Plex Sans KR로 보입니다. 사이트 구현 때 Pretendard 웹폰트를 함께 넣어야 합니다.
- 한국어는 `word-break: keep-all`로 단어 단위 줄바꿈. 가장 작은 글자는 `tag` 12px.

## 레이아웃

- 데스크톱 기준 가로 1440, 콘텐츠 최대 너비 `content-max`(1200px), 가입 양식·핵심 버튼 너비 `form-max`(480px).
- 이미지와 글이 짝인 섹션은 좌우를 번갈아 둡니다(홈 첫 화면 이미지 오른쪽, 브랜드 섹션 이미지 왼쪽).
- 섹션 제목 오른쪽으로 `line` 색 가는 가로선을 이어 그립니다.
- 상품은 4개를 한 줄에, 사진(4:5) → 상품명 → 재료 → 용량·가격 + '예시 가격' 태그 순서.

## 반복 요소

- **버튼** — 주요: `brand` 채움 + 흰 글자, 높이 56. 보조: 투명 + 1px `ink` 테두리, 높이 52(헤더 44). 모든 버튼은 호버 시 `brand-hover` 채움 + `on-brand-hover` 글자. 모서리 `radius-sm`.
- **핵심 행동** — 'P03-B01 이 구성으로 정기배송 신청', 'P04-B01 정기배송 신청하기'. 주요 버튼과 같은 모양, 너비 480.
- **메뉴** — 글자 `ink` 15px Medium. 호버 시 `brand` 2px 밑줄(글자 아래 8px). 현재 페이지는 글자가 `brand`.
- **카드·이미지** — 모서리 `radius-none`, 그림자 없음. 호버 시 사진만 2% 확대.
- **입력·칩** — 높이 48, `line-input` 테두리, `radius-sm`. 선택된 칩은 `brand` 채움 + 흰 글자. 포커스는 `brand` 2px 외곽선.
- **푸터** — `surface-footer` 바탕, 위 `line` 1px. 맨 위에 'Green Issue'(`wordmark-footer`)를 좌우 `space-20`(80px)씩 비우고 가운데 한 줄로 꽉 채웁니다. 크기는 푸터 너비에 맞춰 바뀝니다. 그 아래 `line` 구분선, 왼쪽 SNS 칸(라벨 + 링크 목록), 오른쪽 '상품 가격은 시세를 참고한 예시입니다.'
- **태그** — 12px, `line` 테두리, `radius-xs`. 예: 예시 가격, 루틴 혜택(이 경우만 `brand` 글자·테두리).
- **미정 표시** — 아직 정하지 않은 내용은 `line-input` 점선 위에 `meta` 크기 `ink-muted` 글자로 '… — 추후 결정'.

## 움직임

- 버튼·메뉴 색 전환 0.18초.
- 홈 첫 화면: 페이지를 열 때 0.4초 페이드 한 번. 루틴 결과: 선택을 바꾸면 결과 영역 0.2초 페이드.
- 반복 움직임 없음. 시스템의 '동작 줄이기' 설정이 켜져 있으면 모두 끕니다.

## 말투

믿을 만한 편집자가 조용히 권하듯, 짧고 차분한 존댓말(~해요). 재촉하거나 감탄하지 않습니다.

- "출근 시간과 생활 패턴을 고르면 언제 무엇을 먹을지 정기배송 구성으로 제안해 드려요."
- "이 구성으로 시작하면 첫 배송은 저희가 준비할게요."

문서에 없는 사실(가격, 효능, 후기)은 쓰지 않습니다. 가격은 시세를 참고한 예시이며 항상 '예시 가격'으로 표시합니다.

## 로고

원 안에 새싹 선 그림(심볼)과 'Green Issue' 글자(`logo` 스타일)를 나란히 둡니다. 심볼 파일은 Logos 그룹에 있고, 글자는 이미지가 아닌 텍스트로 넣습니다. 색은 `ink` 한 가지입니다.

## 아직 정하지 않은 것

상품·브랜드 사진, Pretendard 웹폰트 파일, Bague Scout 정식 라이선스, 푸터 SNS 채널, 다크 테마, 모바일 화면 기준.
