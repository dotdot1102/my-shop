# 그린이슈(Green Issue) 시각 디자인 기준

- 기준 문서: docs/01-site-purpose.md, docs/04-site-wireframe.md, docs/05-site-reference.md, PROJECT_CONTEXT.md
- 기준 디자인: Claude Design 캔버스 '그린이슈 메인 페이지'(P-01 홈 · P-02 회원가입·로그인 · P-03 루틴 만들기 · P-04 정기배송 신청), 디자인 시스템 'Green Issue'
- 화면 기준: 데스크톱 가로 1440 (콘텐츠 최대 너비 1200). 모바일은 따로 정함
- 문서 상태: 디자인 시스템 1차 확정본 (2026-11-13, 코드 작업 전)
- 표기: **추후 결정** = 아직 정하지 않은 내용
- 이 문서·디자인 시스템·캔버스의 값은 서로 같아야 함. 한쪽을 고치면 다른 쪽도 함께 고침

## 1. 디자인 원칙

| 원칙 | 내용 | 근거 |
|---|---|---|
| 재료가 주인공 | 화면의 색은 제품·재료 사진에서 나옴. UI는 거의 흰색과 녹흑색, 포인트 그린은 행동을 부르는 곳에만 | 05 R1 |
| 크게 외치지 않기 | 크게 키우는 글자는 페이지마다 한 곳(홈은 첫 화면 제목) + 푸터 워드마크뿐. 나머지 위계는 굵기와 색으로 | 05 전체 정리 |
| 넓은 여백 | 섹션 사이 160, 섹션 제목과 내용 사이 72. 정보는 사진 아래 작고 촘촘하게 | 05 R1 |
| 판촉물처럼 보이지 않기 | 할인 배너·팝업·배지·구매 재촉 없음. 혜택은 차분한 문장 한 줄 | 01 |
| 잡지를 흉내 내지 않기 | 편집자의 감각은 여백·세리프·가는 선으로만. 제호·호수·페이지 번호 같은 잡지 장치는 쓰지 않음 | 01 |

## 4. 레이아웃과 간격

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `content-max` | 1200px | 콘텐츠 최대 너비 |
| `form-max` | 480px | 가입 양식 칼럼, 핵심 행동 버튼 너비 |
| `header-height` | 88px | 공통 헤더 |
| `button-height` | 56px | 주요·핵심 버튼 (보조 52, 헤더 버튼 44) |
| `input-height` | 48px | 입력칸 |

간격 단계: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 72 · 80 · 120 · 160 (`space-1` ~ `space-40`)

| 자리 | 간격 |
|---|---|
| 홈 섹션 사이 | 160 (`space-40`) |
| 흰 띠 위아래 안쪽 | 120 / 140 |
| 섹션 제목 → 내용 | 72 (`space-18`) |
| 이미지 칼럼 ↔ 글 칼럼 | 64 (첫 화면) / 80 (브랜드 섹션) |
| 상품 카드 사이 | 32 (`space-8`) |
| 입력 필드 사이 | 24 (`space-6`) |
| 푸터 워드마크 좌우 | 80 (`space-20`) |

배치 원칙
- 이미지와 글이 짝인 섹션은 좌우를 번갈아 둠: P01-S01 이미지 오른쪽, P01-S04 이미지 왼쪽
- 섹션 제목 오른쪽으로 `line` 가는 가로선
- 상품 4개 한 줄: 사진(4:5) → 상품명 → 재료 → 용량·가격 + '예시 가격' 태그
- P-02는 모든 섹션 가운데 정렬, 480 칼럼

### 모서리

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `radius-none` | 0 | 사진, 이미지 자리, 카드, 상자 |
| `radius-xs` | 2px | 작은 태그 |
| `radius-sm` | 4px | 버튼, 입력칸, 칩, 수량 조절 |

그림자는 쓰지 않음.

## 8. 말투

- 믿을 만한 편집자가 조용히 권하듯, 짧고 차분한 존댓말(~해요). 재촉·감탄 없음
- 예시: "출근 시간과 생활 패턴을 고르면 언제 무엇을 먹을지 정기배송 구성으로 제안해 드려요."
- 혜택 안내 예시: "이 구성으로 시작하면 첫 배송은 저희가 준비할게요." (01)
- 문서에 없는 사실(가격, 효능, 후기)은 쓰지 않음. 가격은 항상 '예시 가격'으로 표시
