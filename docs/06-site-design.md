- 기준 문서: docs/01-site-purpose.md, docs/04-site-wireframe.md, docs/05-site-reference.md, PROJECT_CONTEXT.md

## 1. 디자인 원칙

| 원칙 | 내용 | 근거 |
|---|---|---|
| 재료가 주인공 | 화면의 색은 제품·재료 사진에서 나옴. UI는 거의 흰색과 녹흑색, 포인트 그린은 행동·선택·상태를 알리는 곳에만 | 05 R1 |
| 크게 외치지 않기 | 크게 키우는 글자는 홈 첫 화면 제목 + 푸터 워드마크뿐. 나머지 위계는 굵기와 색으로 | 05 전체 정리 |
| 넓은 여백 | 섹션 사이 160, 섹션 제목과 내용 사이 72. 정보는 사진 아래 작고 촘촘하게 | 05 R1 |
| 판촉물처럼 보이지 않기 | 할인 배너·팝업·구매 재촉 없음. 혜택은 차분한 문장 한 줄 | 01 |
| 잡지를 흉내 내지 않기 | 편집자의 감각은 여백·세리프·가는 선으로만. 제호·호수·페이지 번호 같은 잡지 장치는 쓰지 않음 | 01 |

## 4. 레이아웃과 간격

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `content-max` | 1200px | 콘텐츠 최대 너비 |
| `form-max` | 480px | 가입·로그인·비밀번호 찾기 칼럼, 비회원 주문 조회 양식, 회원 정보 수정 양식, 핵심 행동 버튼 너비 |
| `gutter` | 20px | 좁은 화면의 좌우 여백 |
| `header-height` | 88px | 공통 헤더 |
| `button-height` | 56px | 주요·핵심 버튼 (보조 52, 헤더·작은 버튼 44) |
| `input-height` | 48px | 입력칸 |

간격 단계: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 72 · 80 · 120 · 160 (`space-1` ~ `space-40`)

| 자리 | 간격 |
|---|---|
| 홈 섹션 사이 | 160 (`space-40`) |
| 흰 띠 위아래 안쪽 | 120 / 140 |
| 섹션 제목 → 내용 | 72 (`space-18`) |
| 이미지 칼럼 ↔ 글 칼럼 | 64 (첫 화면) / 80 (브랜드 섹션) |
| 상품 카드 사이 | 32 (`space-8`) |
| 입력 필드 사이 | 20~24 |
| 버튼 나란히 | 8 (마이페이지 · 구성 변경) / 12 (상품 상세 반반) |
| 푸터 워드마크 좌우 | 80 (`space-20`) |

배치 원칙
- 이미지와 글이 짝인 섹션은 좌우를 번갈아 둠: P01-S01 이미지 오른쪽(왼쪽 글 여백 최대 80px, 1100px 이하에서 줄임), P01-S04 이미지 왼쪽
- 섹션 제목 오른쪽으로 `line` 가는 가로선
- 상품 카드: 사진(4:5) → 영문 이름 → 작은 한글 이름 → 재료 → 용량·가격 → 언제·어떻게 → '장바구니 담기' 버튼. 홈은 4개 한 줄, 상품 더보기는 6개 (답변 2026-11-16 — '예시 가격' 태그 없앰)
- 상품 상세: 사진 왼쪽, 정보 오른쪽. '장바구니 담기'와 '주문하기'를 나란히 반반
- 정기배송 신청 · 주문하기 · 장바구니: 왼쪽 목록·입력, 오른쪽 요약 상자 + 그 아래 동의 체크 + 핵심 버튼
- P-02, 비회원 주문 조회: 모든 섹션 가운데 정렬, 480 칼럼
- 마이페이지: 720 칼럼, 칸마다 위에 가는 선

### 모서리

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `radius-none` | 0 | 사진, 이미지 자리, 카드, 상자 |
| `radius-xs` | 2px | 작은 태그·상태 라벨 |
| `radius-sm` | 4px | 버튼, 입력칸, 칩, 수량 조절 |
| (원) | 50% | 헤더 로고 심볼, 장바구니 아이콘 숫자 |

그림자는 쓰지 않음.
