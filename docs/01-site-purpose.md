# 그린이슈(Green Issue) 사이트 목적 정의

- 브랜드: 그린이슈 — 잡지 편집자가 만든 자연주의 식료품 브랜드
- 상품: 당근주스, 케일주스, 사과칩
- 문서 상태: 목적 정의 확정본 (화면·코드 작업 전)
- 변경 기록: 2026-11-12 혜택 구조 변경 — 가입 무료권과 루틴 완성자의 정기배송 첫 회 무료로 나눔 / 배송비 기준 결정 — 5만 원 이상 무료배송, 무료권을 쓴 주문은 함께 담은 상품까지 배송비 무료 / 루틴 혜택 확대 — 루틴 구성 정기배송은 첫 회 무료 + 배송비 매회 무료 + 가입 무료 단품을 첫 상자에 동봉

---

## 1. 사이트 목적 한 문장

> 바쁜 30대 직장인이 간편한 섭취 방법을 확인하고 정기배송을 신청하는 사이트

브랜드 문장:

> 계절이 키운 재료를 그대로 담고 꼭 필요하지 않은 것은 덜어내, 몸이 먼저 알아보는 한 잔과 한 봉지를 만듭니다.

## 2. 주요 방문자와 방문자의 필요

| 구분 | 내용 | 상태 |
|---|---|---|
| 주요 방문자 | 건강은 챙기고 싶지만 성분을 꼼꼼히 볼 시간이 없는 바쁜 30대 직장인 | 확정 |
| 방문자의 필요 | 간편한 섭취 방법: 출근길이나 사무실에서 언제, 어떻게 먹으면 좋은지 알기 | 확정 |
| 주요 기기 | 데스크톱 기준으로 진행 | 확정 |

## 3. 가장 중요한 행동과 보조적인 행동

| 구분 | 내용 | 상태 |
|---|---|---|
| 가장 중요한 행동 | 정기배송 신청 | 확정 |
| 정기배송 조건 | 루틴 구성대로 주 1회 배송, 해지·변경은 조건 없이 언제든 간단하게 | 확정 |
| 체험요소 | 섭취 루틴 만들기: 출근 시간·생활 패턴을 고르면 언제 무엇을 먹을지 정기배송 구성으로 제안 | 확정 |
| 보조적인 행동 | 회원가입하고 단품 1회 무료권 받기 (무료권을 쓴 주문은 배송비 무료) | 확정 |
| 배송비 기준 | 5만 원 이상 구매 시 무료배송. 무료권을 쓴 주문은 함께 담은 다른 상품까지 배송비 무료. 루틴 구성 정기배송은 배송비 매회 무료 | 확정 |
| 루틴 완성 혜택 | 섭취 루틴을 만든 가입자가 루틴 구성으로 정기배송을 신청하면 ① 첫 회 배송 무료 ② 배송비 매회 무료 (5만 원 기준과 무관) ③ 가입 무료 단품을 첫 정기배송 상자에 함께 넣어 보냄 (무료권을 아직 쓰지 않은 경우). 별도 신청 없이 자동 적용 | 확정 |
| 혜택 안내 방식 | 팝업·할인 배너 없이 루틴 결과 화면에서 차분한 문장으로 안내 (예: "이 구성으로 시작하면 첫 배송은 저희가 준비할게요") | 확정 |

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

### 전달하고 싶은 인상 (확정)
- 정직하고 믿을 수 있음: 매주 받아 먹어도 안심되는 재료와 만드는 방식
- 편집자의 감각이 느껴지는 에디토리얼한 분위기

### 피하고 싶은 방향 (확정)
- 판촉물 같은 상업적 느낌: 할인 배너, 팝업, 구매를 재촉하는 연출
- 잡지를 그대로 흉내 낸 표현: 편집자 설정은 감각과 분위기로만 드러냄
